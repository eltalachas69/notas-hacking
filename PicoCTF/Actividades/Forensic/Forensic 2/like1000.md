## Solución
Lo que trata es descomprimir un archivo tar y como nos dice son como 1000, en este caso para resolverlo pues es hacer un script para ejecutarlo y que se nos haga mas facil
```
import tarfile 

for i in range(1000, 0, -1):
	filename = str(i) + '.tar' 
	tar = tarfile.open(filename) 
	tar.extractall() 
	tar.close() 
```
